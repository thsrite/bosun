Bosun UI 风格翻新 · 三方向对比稿

同一套真实界面结构（顶栏 / 首页概览 / 任务板 / 基础控件）分别套用三个风格方向，数据均为虚构示例。三个方向共同修掉现状的几个问题：焦点色过灰（现 --dh-accent 是中性 slate，聚焦几乎不可见）、等待介入的任务卡整卡染色过重、状态用色多达 9 种缺乏主次。

方向 01

深海精修

现有基因收紧 · 迁移成本最低

保留现在的深蓝黑底和顶缘高光分层，只做「收紧」：强调色从不可见的中性灰统一为暖青 teal（导航选中态 / 主按钮 / 聚焦描边共用一色）；等待介入的卡从整卡染色改成左缘 3px 信号条，卡面保持中性；圆角统一 12 / 8 两档；数字用 tabular-nums 对齐。

底 #070a0f 面 #101722 强调 #2dd4bf 边 #253448
方向 02

碳黑仪表

工程感最强 · 与现状差异最大

去掉蓝色调，换纯中性碳黑基底 + 发丝级边线，唯一强调色是琥珀「信号灯」——呼应船上的灯与仪表。圆角收到 8 / 6，标签用大写间隔字距，数字全部等宽字体，无投影无高光，层次全靠明度差。整体最接近 Linear / 终端仪表盘的克制气质。

底 #0a0a0c 面 #131316 强调 #f5b342 边 #2a2a31
方向 03

海图暗青

主题化最强 · 品牌辨识度最高

把「Bosun = 水手长」的航海身份做进底色：青墨绿基底、绿青强调色、状态点带光晕，页面右上角一层极淡的青光呼应海面。圆角放到 14 / 9 更圆润，chip 用全圆角。它和市面上的深蓝黑 / 碳黑工具都拉开距离，是三个方向里辨识度最高、也最「有性格」的一个。

迁移成本最低：改 CSS 变量 + 少量组件类名中：色板全换 + 圆角/字体/标签规则改动多中低：色板全换，结构规则与现状接近
风险翻新感知弱，「变了但说不出哪变了」琥珀强调色与现有 9 色状态系统要重新调和绿底上绿色状态点的层次要仔细调，避免糊成一片
适合场景想快速提质感、不打断迭代想彻底改头换面、立住专业工具人设想为开源发布立一个记得住的品牌脸
我的建议：以 01 为底、吸收 03 的品牌元素分两步走。
第一步落地 01（统一强调色、左缘信号条、圆角与数字规范）——纯 token 级改动，一次 PR 可完成，立刻解决聚焦不可见和等待卡过重两个实际问题；第二步若开源发布需要品牌辨识度，再把底色向 03 的青墨绿平移（同样只动 CSS 变量）。02 最帅但改动面最大，适合当作大版本的整体改版而非本轮翻新。
